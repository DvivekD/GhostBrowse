## ⚡ The Problem: The Modern Web is Broken

Today's web forces humans to act like biological routing switches. To book a simple flight, buy a laptop, or schedule a doctor appointment, users endure:
- **Cookie walls & anti-bot traps** that freeze pages.
- **25-field interactive forms** with opaque pricing markups and hidden baggage fees.
- **Fragmented portals**: opening 8 tabs across Google Flights, Skyscanner, Kayak, and airline portals just to compare.

**GhostBrowser inverts the browser model.** The browser is no longer a human viewer — it is an ephemeral, autonomous execution substrate. You speak or type your high-level intent, and GhostBrowser dispatches a parallel fleet of cloud stealth workers to navigate, scrape, filter, and synthesize the result into a **1-Action Cryptographic Approval Card** in under 20 seconds.

## 🛡️ Cryptographic Proof: How We Guarantee Zero Hallucinations

AI agents frequently hallucinate prices or misread booking dates. GhostBrowser eliminates hallucinations through our **W3C C14N 4-Leaf Merkle Tree**:

```
                         [ Merkle Root Hash ]
                               /       \
                  [ Hash_AB ]             [ Hash_CD ]
                   /       \               /       \
            [ Leaf_A ]   [ Leaf_B ]  [ Leaf_C ]   [ Leaf_D ]
             (Price)      (Flight)    (Route)      (DOM Extract)
```

1. **Leaf A (Price Claim)**: `SHA256(f"PRICE_INR:{price}")`
2. **Leaf B (Flight Identity)**: `SHA256(f"FLIGHT:{airline}:{flight_number}")`
3. **Leaf C (Itinerary)**: `SHA256(f"ITINERARY:{origin}-{destination}:{departure_time}")`
4. **Leaf D (Canonical DOM)**: `SHA256(canonicalize_dom(raw_card_html))`
   - Strips volatile `<script>`, `<style>`, tracking attributes (`nonce`, `data-reactid`), and sorts attributes lexicographically.
5. **Real-Time Client Verification**: When the Approval Card arrives in the browser, the frontend executes native `crypto.subtle.digest("SHA-256")` on all 4 leaves. If any byte was altered or hallucinated, the UI immediately alerts: `⚠ TAMPER DETECTED: Hash Mismatch`.

## 🏃 Quick Start Guide

### 1. Clone & Configure Keys
```bash
git clone https://github.com/DvivekD/GhostBrowse.git
cd GhostBrowse

# Copy environment template
cp .env.example .env
```
Add your free API keys to `.env` (Steel.dev, Deepgram, Cartesia, SambaNova, Google AI Studio, Groq).

### 2. Launch the Backend Engine
```bash
cd apps/engine
uv venv --python 3.12
.venv\Scripts\activate          # Windows: .venv\Scripts\activate, Linux/Mac: source .venv/bin/activate
uv pip install -r requirements.txt
playwright install chromium
uvicorn ghost_engine.main:app --reload --port 8000
```

### 3. Launch the Command Center
```bash
cd apps/web
pnpm install
pnpm dev
```
Open **[http://localhost:3000](http://localhost:3000)** in Chrome or Edge.
